# Skill Nexis — Week 1 Java Fundamentals

This repository contains the Week 1 assignments and mini project for Java Fundamentals.

## Contents

1. `BasicCalculator.java` — performs addition, subtraction, multiplication, and division.
2. `GradeEvaluation.java` — evaluates marks and prints Grade A, B, C, or Fail.
3. `BankManagementApp.java` — menu-driven console application to deposit, withdraw, and check balance.

## Concepts used

- Java syntax, variables, data types, and operators
- `Scanner` for user input
- Conditional statements (`if-else`, `switch`)
- Loops (`do-while`)
- Basic validation for invalid input and amounts
- Formatted output with `printf`

## Requirements

- JDK 17 or later recommended
- VS Code with Java extensions, IntelliJ IDEA, or Eclipse

## How to run

Open a terminal in this folder and compile the program you want to run.

### Calculator

```bash
javac BasicCalculator.java
java BasicCalculator
```

### Grade Evaluation

```bash
javac GradeEvaluation.java
java GradeEvaluation
```

### Bank Management App

```bash
javac BankManagementApp.java
java BankManagementApp
```

Each program has its own `main` method, so compile and run them separately.

## Grade rules

- 80–100: Grade A
- 60–79: Grade B
- 40–59: Grade C
- 0–39: Fail

These grade ranges are simple example rules for this assignment; use your instructor's ranges if different.

## Note

The bank app is an educational console project only. It does not connect to a real bank or store account information.
